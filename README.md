# Kochi Metro multi-stop journey UX

An interactive portfolio case study extending the current KMRL booking experience with an Uber-like multi-stop route editor.

**[View the live prototype](https://kochi-metro-multistop-ux.bijubv.chatgpt.site)**

## The idea

The current ticket flow is optimised for a direct entry-to-exit journey. This concept keeps that simple default while progressively revealing controls for travellers who need to add intermediate stops.

## Prototype features

- Add up to three intermediate stops
- Reorder or remove stops without rebuilding the route
- Catch duplicate stations before fare review
- Configure one-way or round-trip travel for up to six passengers
- Review a responsive route and illustrative fare summary
- Navigate with labelled controls and visible keyboard focus states

## Design direction

The concept extends the existing product language—metro teal, airy white surfaces, icon-led labels, soft elevation, and rounded geometry—while strengthening information hierarchy, validation, responsive behaviour, and route visibility.

## Run locally

Serve the `dist` directory with any static HTTP server and open the local URL in a browser. The project has no build step or runtime dependencies.
